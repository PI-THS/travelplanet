# 河馬星球

5 歲小朋友玩嘅 iPad／電腦網頁遊戲。主角係河馬，喺河馬星球嘅大島自由行走，行近 NPC 撳「傾偈」，就用火車遊戲（Kidsgame）一樣嘅題目卡答 4 題。冇建設、冇經營，淨係問答。

## 玩法
- 開 `index.html`（要上網載入 three.js）。撳大圓掣開始。
- 郁：手指喺畫面任何位置按住拖（浮動搖桿）、鍵盤方向鍵／WASD、或者撳地面／撳 NPC 自動行過去。撳河馬會叫＋跳。
- 行近 NPC（頭上有 ? 泡泡）出「傾偈」掣 → 聽佢介紹 → 撳「好呀」→ 答 4 題（廣東話讀題，英文題讀英文）。答啱 +1 星星。
- **能量**：河馬有 5 格能量（左上閃電）。每撳「好呀」同一位 NPC 玩問答扣 1 格；冇能量就傾唔到偈，頭上箭嘴指向最近嘅池塘。行入池塘（全島 2 個）飲水，每 0.9 秒回復 1 格。
- 答完 NPC 頭上變星星。24 位動物 NPC 全部玩過會有「河馬星球小博士」畫面。進度存喺瀏覽器（localStorage），封面左下有「清除進度」。
- 難度：累積答啱 15 題升至 2 級、45 題升至 3 級（Kidsgame 嘅 `makeQ(type, level)`）。

## 材料來源
- **地圖**：「真．旅遊星球」（`THS/game/index.html` 嘅圓形島 `LAYOUTS`，×2.2，樹少、島面積約擴大 1.9 倍）：中央廣場＋噴水池、餐廳、服務中心、市場、農場（穀倉、風車、稻草人）、兩個池塘（河馬飲水補能量）、飛碟站、碼頭＋郵輪、酒店、樂園（摩天輪、帳篷、氣球）、博物館、燈塔。全部 three.js 即時砌。
- **題目**：`src/kids/questions_v1.js`、立體圖示 `icons.js`／`icons2.js`、題目卡 CSS `base.css`／`game.css`，原封不動複製自 `4_Claude/Kidsgame/src`（中文、英文、數學、推理，共 33 種題型）。
- **NPC**：24 位動物（熊、豬、貓、馬騮、牛、小雞、青蛙、魚、烏龜、蝴蝶、鯨魚、鴨仔、企鵝、獅子、大象、長頸鹿、熊貓、老虎、狐狸、老鼠、蝸牛、兔子、狗、蜜蜂），名字就係動物名；模型取自 Kidsgame `icons2.js` 畫過嘅動物（圓頭動物配可愛身體，大象等全身模型直接放大）。各出 2 科題（老虎四科都出）。頭上冇「?」，答完先出星星。

## 檔案
- `src/kshim.js` 題庫要用嘅小工具、音效、語音
- `src/world.js` 島嶼地圖／建築／碰撞
- `src/chars.js` 河馬、NPC 模型、NPC 名單
- `src/main.js` 移動、鏡頭、傾偈、答題流程、存檔
- `src/hippo.css`、`src/head.html`
- `build.py`：`python3 build.py` 砌出單一 `index.html`（只寫 `Game/index.html`）

題庫有更新時，將 Kidsgame 新版 `questions_v1.js`／`icons*.js` 複製返入 `src/kids/` 再 build。

另：已禁止 iPad 雙指放大縮小、雙擊放大、長按選字。
